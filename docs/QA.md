# Проверка работающего приложения

Дата: 23 сентября 2026. Среда: Windows, Go 1.27.1, Node.js, Next.js 16.3.6, Chrome 153 через agent-browser. Приложение действительно запущено на http://localhost:3000; API на loopback 8080. При проверке использовались только синтетические профили. Сервер и браузер не подменялись статическими макетами.

## Автоматические проверки

`npm test`: **12 тестов PASS**, итоговый прогон 9.629 с. `npm run build`: успешно, TypeScript и production-сборка Next.js проходят.

## Браузерный сквозной сценарий

1. Вход `employee` (E0002). У исходного профиля соответствие целевой роли 62%. Первым предложен System Design Fundamentals; раскрываются несколько фактических оснований.
2. «Выбрать шаг» → дата → отдельное подтверждение. Создана CSV-заявка pending_manager, в интерфейсе показан следующий ответственный.
3. Выход → вход `manager` E0175. Заявка доступна именно непосредственному руководителю. «Согласовать» + подтверждение → approved.
4. employee отправил подробный текст демонстрационной работы с явным указанием, что внешнее обучение не подтверждено провайдером → pending_hr. Прогресс ещё не изменился.
5. hr рассмотрел результат и записал основание → completed. Прирост: SK_API_DESIGN +1, SK_SYSTEM_DESIGN +1. Соответствие цели **62% → 66%**. Четыре записи истории.
6. После полного перезапуска backend/production frontend старая сессия стала недействительной. Повторный вход показал те же 66%, одно завершение и четыре записи аудита: проверена именно файловая долговечность, а не только React-состояние. В production браузерный fetch /api/workspace занял **11 мс** в этом локальном замере.

Дополнительно через интерфейс:

- HR загрузил fixtures/employees.json + activity_history.csv: стало 203 профиля и 2746 записей истории. Создал аккаунт jury-demo; новый сотрудник успешно вошёл.
- Из его браузерной сессии живой сервер вернул 403 на чужой профиль E0002, accounts и import; собственный workspace — 200.
- Сохранение карьерной цели; поиск в каталоге и пустое состояние; исходная история и аудит; справка с реальными ссылками Halyk, Kumo, bloub.
- Нажатие «Получить совет ИИ» без ключа: видимое сообщение «ИИ недоступен: GEMINI_API_KEY не задан на сервере», не модельный текст.
- HR-поиск сотрудника, профиль навыков, фильтры «Развить»/«На цели», клавиатурный обход диалога и Escape. Фокус удерживается внутри и возвращается к «Посмотреть навыки».
- Реальное изменение SVG path bloub между кадрами; рабочий интерфейс использует Manrope, проверено document.fonts для русского/латиницы.

## Визуальная и доступная работа

- Проверены ширины 1440, 768, 390, 320. На 390/320 document.scrollWidth совпадает с шириной viewport.
- Проверено CSS-увеличение 200% при viewport 1440: исправлено перекрытие колонок через container queries; итог scrollWidth=1440 и overlap=false. Это конкретная проверка масштабирования, не обещание формальной сертификации доступности.
- Axe 4.12.1 WCAG 2 A/AA: после исправления aria-label шкал на экране маршрута 0 violations. Текст SVG попал в incomplete; независимо проверена пара #5f7068 / #ffffff — **5.24:1**.
- Отдельный аудит HR-диалога обнаружил недостаточный контраст вторичного текста; цвета исправлены до #52665a. Повторный аудит production-версии: 0 violations. Focus guards Base UI требуют ручной оценки; клавиатурный цикл и возврат фокуса проверены. Декоративная точка-разделитель остаётся в incomplete автоматического анализа контраста.
- Изучены cmap реальных WOFF2 для 400/500/600/700: русский и латиница присутствуют. Не все казахские символы и знак тенге есть в этой поставке Manrope; казахский интерфейс использует системный шрифт с поддержкой казахской кириллицы. Проверены переключение языка, казахские даты и числа, поиск по переведённым названиям и мобильная ширина 390 px. Подробности — [LOCALIZATION.md](LOCALIZATION.md).

Скриншоты находятся локально в `artifacts/`: final-desktop.png, final-mobile.png, employee-submitted.png, hr-confirmed.png, hr-dashboard.png, hr-import-accounts.png, ai-unavailable.png, catalog-empty.png, zoom-200-fixed.png. Это реальные захваты браузера.

## Что не проверено / не реализовано

- Живой Gemini: нет API-ключа; исходный датасет нельзя передавать наружу. Качество настоящих модельных рекомендаций на закрытых профилях жюри неизвестно. Доказанное преимущество относится к многофакторным проверкам и контрпримерам, не к победе в оценке.
- Внешняя LMS, MyHalyk, SSO, календарь, мессенджеры, выдача сертификатов, реальное проведение обучения и повышение должности не интегрированы. Проверка текстового результата HR — действие прототипа. Для демонстрации оно допустимо раньше будущей даты сессии.
- CSV не рассчитан на несколько writer-процессов, большие объёмы, high availability или аудит, защищённый от администратора. Сессии в памяти, нет восстановления пароля, MFA, отзыва отдельных сессий и production-управления секретами.
- Награды/валюта, peer recognition, конструктор событий, реальный прогноз увольнения и уведомления — не реализованы, в обязательный объём Case 1 не входят.
- Это локальные замеры на данной машине. Первичная компиляция dev-сервера занимала больше 2 секунд; требование отклика проверялось на готовом приложении. Нагрузочные тесты и независимый security audit не проводились.
