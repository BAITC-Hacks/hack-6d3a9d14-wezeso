# Supabase SQL

Follow the [deployment guide](../docs/SUPABASE.md).

- **New database:** run the private [`../data/supabase-migration.sql`](../data/supabase-migration.sql), generated by `npm run db:export`. It includes schema, saved data and account hashes.
- **Existing initialized database:** run [`upgrade.sql`](upgrade.sql), or `npm run db:migrate`.
- **Check deployment:** run [`verify.sql`](verify.sql), or `npm run db:verify`.
- **Schema reference:** [`schema.sql`](schema.sql) creates all tables and security; it cannot initialize a usable app alone.

Run as the database owner. Do not seed example courses before importing a fresh snapshot. Keep private exports out of Git.

Bundles are generated from `backend/migrations/` with `npm run db:sql`. They are SQL Editor/psql files, not a Supabase CLI migration-history directory. No Supabase API keys or Auth configuration are needed.
